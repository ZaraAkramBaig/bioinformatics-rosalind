Watch the DP table fill, then trace the alignment back

The table and traceback path come from edit_distance_alignment.py, running on the Python server. This page lets you step through them: first dp[i][j] is filled one cell at a time, then the code walks back from the bottom-right cell to build the alignment. When there's a tie, it tries left, then diagonal, then up.
