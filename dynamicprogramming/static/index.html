Watch the tails array grow, then follow the parents back

Every step comes from liss.py, running on the Python server. For each number x, the code finds pos = bisect_left(tails, x). It either adds x to the end of tails or replaces a larger value, and it records a parent link. pos + 1 is the length of the longest increasing subsequence that ends at x. That's the dp[i] value of the dynamic programming solution.

The DP idea

dp[i] = length of the longest increasing subsequence ending at arr[i] dp[i] = 1 + max(dp[j]) for j < i, arr[j] < arr[i] O(n²) if you check every j. liss.py does it in O(n log n): pos = bisect_left(tails, x) dp[i] = pos + 1 parent[i] = tails_idx[pos - 1]
